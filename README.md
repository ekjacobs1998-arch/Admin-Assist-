# Admin-Assist-
AI - Powered Administrative Productivity Assistant 

## Project Overview
The AI Administrative Productivity Assistant is a web application designed to improve workplace productivity by using Artificial Intelligence to simplify administrative tasks, improve communication and support time management.

## Features Implemented
1. **Smart Email Generator** – Helps users generate professional emails using different tones and audiences.
2. **Meeting Notes Summarizer** – Summarises meeting notes, identifies key decisions and extracts action items.
3. **AI Task Planner and Scheduler** – Helps users organise daily and weekly tasks, priorities and deadlines.
4. **Dashboard** – Provides an overview of tasks, completed activities and upcoming deadlines.
5. **Responsive Design** – Supports desktop, laptop, tablet and mobile screens.
6. **Responsible AI Disclaimer** – Reminds users to verify AI-generated information and use AI responsibly.
